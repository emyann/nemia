## Per record kind, for the owner

- Subscription (its file and its delivery): no row of the measure reads it; the deliverer reads it per subscription per pass, a few
  small JSON files, now decoded by the model's `Delivery` on write only.
- Revision ledger: read inside a tick pass (the pins), tickPass ×1.01 cold and ×1.01 warm of the control: the append's
  `Revision` check costs nothing a pass shows. One small file per kind and name.
- Feed: feedFromCursor ×1.01 cold and ×1.02 warm of the control, 22.2 ms for 1000 lines from a cursor; an append now decodes
  each line through `FeedLine` before it writes. The feed is one append-only file read from a byte offset.
- Runs (run list, stats, a run's page): not these doors'; they stay what S2 measured on a bigger store, and stats remains the costliest
  read (~5.4 s cold).
