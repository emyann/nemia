## Planned <Badge text="planned" variant="caution" />

These terms are designed but not built yet. No page explains them until they ship.

- **Factory template** <Badge text="planned" variant="caution" />: a package you create a factory from. It holds workflows, agents, and skills in one folder, is shared as an archive, and is applied, never run.
- **Definition, instance and package** <Badge text="planned" variant="caution" />: the three kinds of object the template design settled on. A definition (a skill, an agent, a workflow) does nothing on its own. An instance (a factory, a run, a task, a subscription) has one controller, and only that controller writes its status. A package (the template) is applied to create a factory.
- **The factory's controller** <Badge text="planned" variant="caution" />: a controller that would apply a template to a factory and keep its workflows, agents, and hires as applied. It would upgrade the factory with a three-way merge and report conflicts in its status.
