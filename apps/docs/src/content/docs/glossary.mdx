## Planned <Badge text="planned" variant="caution" />

These terms are designed and not built yet. No page explains them until they land.

- **Factory template** <Badge text="planned" variant="caution" />: a package a factory is made from: its workflows, agents and skills in one folder, shared as an archive, applied and never run.
- **Definition, instance and package** <Badge text="planned" variant="caution" />: the kinds the template workbench settled. A definition (a skill, an agent, a workflow) is inert; an instance (a factory, a run, a task, a subscription) has one controller, which alone writes its status; a package, the template, is applied to make a factory.
- **The factory's controller** <Badge text="planned" variant="caution" />: the controller that would apply a template to a factory, keep its workflows, agents and hires as applied, and upgrade it by a three-way merge, reporting conflicts as status.
